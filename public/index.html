      Frequently asked questions

      कैसे डाउनलोड करें?How do I download?
      Instagram में Share → Copy link दबाएँ, लिंक ऊपर बॉक्स में पेस्ट करें, "डाउनलोड" दबाएँ, प्रीव्यू देखें और जो आइटम चाहिए उसका डाउनलोड बटन दबाएँ। कैरोसेल में "सब डाउनलोड करें" भी मिलता है।In Instagram tap Share → Copy link, paste it into the box above, press Download, check the preview and press Download on the item you want. Carousels also have “Download all”.
      कौन-सा कंटेंट सपोर्टेड है?What content is supported?
      आपके अपने (कनेक्टेड) अकाउंट की रील, वीडियो, फ़ोटो, कैरोसेल और स्टोरी — आधिकारिक Instagram API से। साथ ही Public कंटेंट, अगर साइट एडमिन ने कोई अधिकृत स्रोत जोड़ा हो। कृपया सिर्फ़ वही कंटेंट सेव करें जो आपका हो या जिसकी आपको अनुमति हो।Reels, videos, photos, carousels and Stories of your own (connected) account through the official Instagram API, plus public content where the site admin has connected an authorised source. Please save only content you own or have permission for.
      डाउनलोड में एरर क्यों आता है?Why do I get a download error?
      आम कारण: लिंक गलत है; कंटेंट Private है या हट चुका है (स्टोरी 24 घंटे में खत्म होती हैं); वीडियो कनेक्टेड अकाउंट का नहीं है; API की सीमा/Key की समस्या; या इंटरनेट कटा। एरर संदेश कारण बताता है — नेटवर्क की वजह से फेल हुआ डाउनलोड "फिर कोशिश करें" से दोबारा चल जाता है।Common causes: a wrong link; the content is private or removed (Stories expire after 24 hours); the media is not from the connected account; an API limit or key problem; or a lost connection. The message tells you which — a download that failed because of the network can be resumed with “Retry”.
      मेरी प्राइवेसी का क्या?What about my privacy?
      हम आपका Instagram पासवर्ड कभी नहीं माँगते और मीडिया फ़ाइलें सर्वर पर सेव नहीं करते। डाउनलोड हिस्ट्री सिर्फ़ आपके ब्राउज़र में रहती है (लिंक, प्रकार, तारीख़) और एक क्लिक में मिट जाती है। साइट सिर्फ़ गुमनाम गिनतियाँ रखती है, IP पते नहीं। विवरण: प्राइवेसी पॉलिसी।We never ask for your Instagram password and never store media files on the server. Your history stays in your browser (link, type, date) and is removed with one click. The site keeps only anonymous counters, no IP addresses. Details: Privacy Policy.
      कौन-से डिवाइस सपोर्टेड हैं?Which devices are supported?
      Android, iPhone/iPad और कंप्यूटर के आधुनिक ब्राउज़र। Android में फ़ाइल Downloads फ़ोल्डर में जाती है। iPhone में Files → Downloads में सेव होती है, और "Photos में सेव करें" से Share शीट में Save Video/Image चुन सकते हैं। साइट को ऐप की तरह इंस्टॉल भी कर सकते हैं — पर डाउनलोड के लिए इंटरनेट ज़रूरी है।Modern browsers on Android, iPhone/iPad and computers. On Android files go to your Downloads folder. On iPhone they are saved to Files → Downloads, and “Save to Photos” opens the share sheet where you choose Save Video/Image. You can also install the site as an app — downloading still needs internet.
      क्वालिटी की सीमाएँ क्या हैं?What are the quality limitations?
      फ़ाइल बिना re-encode किए दी जाती है, इसलिए क्वालिटी वही है जो स्रोत देता है। अगर स्रोत एक से ज़्यादा क्वालिटी देता है तो चुनने का विकल्प दिखता है; वरना सिर्फ़ उपलब्ध क्वालिटी मिलती है। अवधि, रेज़ोल्यूशन और आकार तभी दिखते हैं जब वे असल में उपलब्ध हों।Files are passed through without re-encoding, so quality equals what the source provides. If the source offers several qualities you can choose; otherwise you get the single available one. Duration, resolution and size are shown only when they are really available.
      क्या Private अकाउंट का कंटेंट डाउनलोड होगा?Can I download from private accounts?
      नहीं। Private कंटेंट, लॉगिन या DRM जैसे एक्सेस नियंत्रण को बायपास नहीं किया जाता।No. Private content is never accessed and login, DRM or other access controls are never bypassed.
      "API कॉन्फ़िगर नहीं है" का क्या मतलब है?What does "API not configured" mean?
      यह साइट सिर्फ़ अधिकृत API से काम करती है। साइट के एडमिन ने अभी API Key/Token सेट नहीं किया है। (एडमिन: README और .env.example देखें।)This site only works through authorised APIs and the admin has not set an API key/token yet. (Admins: see README and .env.example.)
